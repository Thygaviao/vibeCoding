# AGENTS.md

## Цель проекта
Создать Telegram-бота на языке Kotlin, который по команде выдает cowSay с одной случайной фразой из набора индусских скамерских цитат (100+ фраз). Бот должен быть простым, автономным, без подключения к БД.

## Стек технологий
- Kotlin (JVM)
- Telegram Bot API (через библиотеку org.telegram:telegrambots)
- cowSay — реализовать либо нативно, либо через Kotlin-библиотеку/ASCII шаблон
- Gradle Kotlin DSL

## Структура проекта
- `/src/main/kotlin`: основной код бота
- `/src/main/resources`: файл с цитатами (`quotes.txt`)
- `/build.gradle.kts`: скрипт сборки
- `/README.md`: инструкция по запуску
- `/tests`: (опционально) — модульные тесты генерации cowSay

## Поведение бота
- При вводе команды `/quote`, бот отвечает cowSay ASCII-артом с одной случайной фразой из `quotes.txt`
- Фразы загру
